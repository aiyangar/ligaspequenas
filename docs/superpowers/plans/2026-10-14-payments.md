# Player Payments (#2) and "Quién debe" (#3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admins record, edit and delete a player's payments from the player detail page (readonly users see them), and every user gets a **Quién debe** page that splits active players into **Con adeudo** (with the open charges), **Sin pagos** and **Al corriente**, backed by a reusable `player_payment_status` view.

**Architecture:** One migration (`0014`) adds the `security_invoker` view `player_payment_status` (one row per player, `payment_state` text). A new `src/payments/` module holds the data layer (`payments.ts`), the `PaymentDialog`, the self-loading `PlayerPaymentsSection` (wired into `PlayerFormPage` under the documents section) and, in Part 2, the `DebtorsPage` that replaces the `/quien-debe` placeholder. "Con adeudo" follows the open payment rows; the view only splits the rest.

**Tech Stack:** React 19.2, react-router-dom 7, MUI 9, `@supabase/supabase-js` 2.108 (PostgREST), Vitest 4 + Testing Library + user-event, TypeScript (`tsc -b`), ESLint, pnpm; Postgres on remote Supabase (`eksbaugyypadtanyjcje`) via the Supabase MCP; pgTAP in schema `extensions`.

**Spec:** `docs/superpowers/specs/2026-10-14-payments-design.md` (read it before starting; § numbers below refer to it).

## Review Focus

- **An amount typed with a decimal comma** (`150,50`, the usual way on a Mexican phone keyboard) must save as `150.5`, while `1e3`, `0x10`, `1,000.50`, `0`, `1.234` and blanks are rejected before any Supabase call (pinned in Task 2 `validatePayment`/`createPayment` tests and Task 3 dialog tests).
- **Registering a payment late in the evening** (after 18:00 in Monterrey, when UTC is already tomorrow) must default the date to today, and a stored `2026-10-04` must display as `04/10/2026`, not the 3rd (pinned in Task 2 `localToday` + TZ guard + `formatPaymentDate` tests).
- **Pressing Enter inside the payment dialog**, which sits inside the player's `<form>` in the React tree, must not submit the player form (pinned in Task 5 regression test: `updatePlayer` never called).
- **Pressing Escape, the backdrop or Cancelar while a payment is saving** must not close the dialog, so a failure that arrives afterwards is shown in the still-open dialog instead of being lost (pinned in Task 3 in-flight close test).
- **A payment edited or deleted between the two "Quién debe" reads** must never hide an open charge: Con adeudo always follows the open rows, in both race directions (pinned in Task 6 `buildDebtGroups` race tests).
- **Editing or deleting a payment that RLS silently filtered** (readonly forcing it, or a row deleted in another tab) must report `No se encontró el pago o no tienes permiso.` instead of a fake success toast (pinned in Task 2 zero-row tests and Task 4 delete-error test).

### How to run pgTAP against the remote (Task 1)

Facts (project memory, verified on migrations 0001–0013):
- pgTAP lives in schema `extensions`: always call `extensions.plan(n)`, `extensions.is(...)`.
- `mcp__supabase__execute_sql` returns only the **last** statement's result and runs the whole call in one implicit transaction that **commits** (fixtures persist). `set_config(..., true)` lives only for that call — so **acting as a role and the assertion that depends on it must be in the same call** (spec §3.2).
- Value assertions: one call = `select extensions.plan(N);` … setup statements … then a **single final** `select extensions.is(...) union all select extensions.is(...) …;` (or `select extensions.is(...) from r …`). Pass iff no returned row starts with `not ok`.
- Structural pgTAP (`has_view`, `has_column`) does not work across the call boundary; check catalog rows with `extensions.is(...)` instead.
- The remote has **no `tests` schema**, so `tests.act_as` from `0002_rls.test.sql` does not exist there. Act as a user with the equivalent inline pair:

```sql
select set_config('role', 'authenticated', true),
       set_config('request.jwt.claims', '{"sub":"<uuid>","role":"authenticated"}', true);
```

Act as `anon` with `select set_config('role', 'anon', true), set_config('request.jwt.claims', '{"role":"anon"}', true);` and return to `postgres` with `select set_config('role', 'postgres', true);`.

import { supabase } from '../lib/supabase'

export type PaymentConcept = 'inscripcion' | 'mensualidad' | 'uniforme' | 'otro'
export type PaymentMethod = 'efectivo' | 'transferencia'
export type PaymentStatus = 'pagado' | 'pendiente' | 'parcial'

export interface PaymentRow {
  id: string
  tenant_id: string
  player_id: string
  concept: PaymentConcept
  concept_note: string | null
  amount: number
  payment_date: string
  method: PaymentMethod
  status: PaymentStatus
  created_at: string
  updated_at: string
}

export interface PaymentFormValues {
  concept: PaymentConcept
  concept_note: string
  amount: string
  payment_date: string
  method: PaymentMethod
  status: PaymentStatus
}

export type PaymentFormErrors = Partial<Record<keyof PaymentFormValues, string>>

export interface MutationResult {
  ok: boolean
  error?: string
}

export const PAYMENT_CONCEPTS: readonly PaymentConcept[] = ['inscripcion', 'mensualidad', 'uniforme', 'otro']
export const PAYMENT_METHODS: readonly PaymentMethod[] = ['efectivo', 'transferencia']
export const PAYMENT_STATUSES: readonly PaymentStatus[] = ['pagado', 'pendiente', 'parcial']

export const CONCEPT_LABELS: Record<PaymentConcept, string> = {
  inscripcion: 'Inscripción',
  mensualidad: 'Mensualidad',
  uniforme: 'Uniforme',
  otro: 'Otro',
}

export const METHOD_LABELS: Record<PaymentMethod, string> = {
  efectivo: 'Efectivo',
  transferencia: 'Transferencia',
}

export const PAYMENT_STATUS_LABELS: Record<PaymentStatus, string> = {
  pagado: 'Pagado',
  pendiente: 'Pendiente',
  parcial: 'Parcial',
}

export const PAYMENT_STATUS_COLOR: Record<PaymentStatus, 'success' | 'warning' | 'default'> = {
  pagado: 'success',
  parcial: 'warning',
  pendiente: 'default',
}

const PAYMENT_COLUMNS =
  'id, tenant_id, player_id, concept, concept_note, amount, payment_date, method, status, created_at, updated_at'
const AMOUNT_PATTERN = /^\d{1,8}(\.\d{1,2})?$/
const NOT_FOUND_MESSAGE = 'No se encontró el pago o no tienes permiso.'
const money = new Intl.NumberFormat('es-MX', { style: 'currency', currency: 'MXN' })

export function localToday(): string {
  const now = new Date()
  const month = String(now.getMonth() + 1).padStart(2, '0')
  const day = String(now.getDate()).padStart(2, '0')
  return `${now.getFullYear()}-${month}-${day}`
}

export function emptyPayment(today: string = localToday()): PaymentFormValues {
  return {
    concept: 'inscripcion',
    concept_note: '',
    amount: '',
    payment_date: today,
    method: 'efectivo',
    status: 'pagado',
  }
}

export function paymentToValues(row: PaymentRow): PaymentFormValues {
  return {
    concept: row.concept,
    concept_note: row.concept_note ?? '',
    amount: String(row.amount),
    payment_date: row.payment_date,
    method: row.method,
    status: row.status,
  }
}

export function formatPaymentDate(date: string): string {
  // new Date('YYYY-MM-DD') is UTC midnight and shows the previous day in Monterrey
  const [year, month, day] = date.split('-')
  return `${day}/${month}/${year}`
}

export function normalizeAmount(raw: string): string {
  return raw.trim().replace(',', '.')
}

export function validatePayment(values: PaymentFormValues): PaymentFormErrors {
  const errors: PaymentFormErrors = {}
  if (values.concept === 'otro' && values.concept_note.trim() === '') {
    errors.concept_note = 'Describe el concepto.'
  }
  const amount = normalizeAmount(values.amount)
  if (!AMOUNT_PATTERN.test(amount) || Number(amount) <= 0) {
    errors.amount = 'Ingresa un monto mayor a 0 con hasta 2 decimales.'
  }
  if (values.payment_date === '') errors.payment_date = 'Ingresa la fecha.'
  return errors
}

export function paymentText(row: Pick<PaymentRow, 'concept' | 'concept_note'>): string {
  const label = CONCEPT_LABELS[row.concept]
  return row.concept_note ? `${label} — ${row.concept_note}` : label
}

export function formatMoney(amount: number): string {
  return money.format(amount)
}

export function paymentErrorMessage(message: string): string {
  if (/row-level security|unauthorized|403/i.test(message)) return 'No tienes permiso para esta acción.'
  return message
}

function normalizeRow(row: PaymentRow): PaymentRow {
  return { ...row, amount: Number(row.amount) }
}

function toRecord(values: PaymentFormValues) {
  return {
    concept: values.concept,
    concept_note: values.concept_note.trim() || null,
    amount: Number(normalizeAmount(values.amount)),
    payment_date: values.payment_date,
    method: values.method,
    status: values.status,
  }
}

export async function fetchPlayerPayments(playerId: string): Promise<PaymentRow[]> {
  const { data, error } = await supabase
    .from('payments')
    .select(PAYMENT_COLUMNS)
    .eq('player_id', playerId)
    .order('payment_date', { ascending: false })
    .order('created_at', { ascending: false })
  if (error) throw new Error(error.message)
  return ((data as PaymentRow[] | null) ?? []).map(normalizeRow)
}

export async function createPayment(
  playerId: string,
  tenantId: string,
  values: PaymentFormValues,
): Promise<MutationResult> {
  const { error } = await supabase
    .from('payments')
    .insert({ ...toRecord(values), player_id: playerId, tenant_id: tenantId })
  if (error) return { ok: false, error: paymentErrorMessage(error.message) }
  return { ok: true }
}

// RLS filters update/delete targets silently, so zero returned rows means nothing changed
export async function updatePayment(id: string, values: PaymentFormValues): Promise<MutationResult> {
  const { data, error } = await supabase.from('payments').update(toRecord(values)).eq('id', id).select('id')
  if (error) return { ok: false, error: paymentErrorMessage(error.message) }
  if (!data || data.length === 0) return { ok: false, error: NOT_FOUND_MESSAGE }
  return { ok: true }
}

export async function deletePayment(id: string): Promise<MutationResult> {
  const { data, error } = await supabase.from('payments').delete().eq('id', id).select('id')
  if (error) return { ok: false, error: paymentErrorMessage(error.message) }
  if (!data || data.length === 0) return { ok: false, error: NOT_FOUND_MESSAGE }
  return { ok: true }
}

The dialog initializes its values from `payment` once, at mount. It has **no `<form>`** (spec §2): Guardar uses `onClick`. On `{ ok: true }` it calls `onClose()`; on `{ ok: false }` it stays open with an `Alert` and keeps the values. **While a save is in flight the dialog cannot be closed**: `Cancelar` is disabled and the `Dialog`'s own `onClose` (Escape / backdrop) is ignored — otherwise a failure arriving after the close would be lost and the user would believe the payment was saved.

```tsx
import { useRef, useState } from 'react'
import Alert from '@mui/material/Alert'
import Button from '@mui/material/Button'
import Dialog from '@mui/material/Dialog'
import DialogActions from '@mui/material/DialogActions'
import DialogContent from '@mui/material/DialogContent'
import DialogTitle from '@mui/material/DialogTitle'
import InputAdornment from '@mui/material/InputAdornment'
import Stack from '@mui/material/Stack'
import TextField from '@mui/material/TextField'
import {
  CONCEPT_LABELS,
  METHOD_LABELS,
  PAYMENT_CONCEPTS,
  PAYMENT_METHODS,
  PAYMENT_STATUSES,
  PAYMENT_STATUS_LABELS,
  emptyPayment,
  paymentToValues,
  validatePayment,
} from './payments'
import type {
  MutationResult,
  PaymentConcept,
  PaymentFormErrors,
  PaymentFormValues,
  PaymentMethod,
  PaymentRow,
  PaymentStatus,
} from './payments'

export interface PaymentDialogProps {
  open: boolean
  payment: PaymentRow | null
  onSave: (values: PaymentFormValues) => Promise<MutationResult>
  onClose: () => void
}

const NATIVE_SELECT = { select: { native: true }, inputLabel: { shrink: true } }

export function PaymentDialog({ open, payment, onSave, onClose }: PaymentDialogProps) {
  const [values, setValues] = useState<PaymentFormValues>(() =>
    payment ? paymentToValues(payment) : emptyPayment(),
  )
  const [errors, setErrors] = useState<PaymentFormErrors>({})
  const [saveError, setSaveError] = useState<string | null>(null)
  const [saving, setSaving] = useState(false)
  // synchronous guard: `saving` only disables the button after a re-render
  const inFlight = useRef(false)

  function update<K extends keyof PaymentFormValues>(key: K, value: PaymentFormValues[K]) {
    setValues((v) => ({ ...v, [key]: value }))
  }

  async function handleSave() {
    if (inFlight.current) return
    const found = validatePayment(values)
    setErrors(found)
    if (Object.keys(found).length > 0) return
    inFlight.current = true
    setSaving(true)
    setSaveError(null)
    try {
      const res = await onSave(values)
      if (res.ok) onClose()
      else setSaveError(res.error ?? 'No se pudo guardar el pago.')
    } finally {
      inFlight.current = false
      setSaving(false)
    }
  }

  return (
    <Dialog
      open={open}
      onClose={() => {
        if (!saving) onClose()
      }}
      fullWidth
      maxWidth="sm"
      aria-labelledby="payment-dialog-title"
    >
      <DialogTitle id="payment-dialog-title">{payment ? 'Editar pago' : 'Registrar pago'}</DialogTitle>
      <DialogContent>
        <Stack spacing={2} sx={{ mt: 1 }}>
          <TextField
            select
            label="Concepto"
            value={values.concept}
            onChange={(e) => update('concept', e.target.value as PaymentConcept)}
            slotProps={NATIVE_SELECT}
          >
            {PAYMENT_CONCEPTS.map((c) => (
              <option key={c} value={c}>
                {CONCEPT_LABELS[c]}
              </option>
            ))}
          </TextField>
          <TextField
            label="Detalle"
            value={values.concept_note}
            onChange={(e) => update('concept_note', e.target.value)}
            required={values.concept === 'otro'}
            error={Boolean(errors.concept_note)}
            helperText={errors.concept_note ?? 'Obligatorio cuando el concepto es Otro'}
          />
          <TextField
            label="Monto"
            type="text"
            value={values.amount}
            onChange={(e) => update('amount', e.target.value)}
            error={Boolean(errors.amount)}
            helperText={errors.amount ?? 'Lo pagado hasta hoy en este concepto'}
            slotProps={{
              htmlInput: { inputMode: 'decimal' },
              input: { startAdornment: <InputAdornment position="start">$</InputAdornment> },
            }}
          />
          <TextField
            label="Fecha"
            type="date"
            value={values.payment_date}
            onChange={(e) => update('payment_date', e.target.value)}
            error={Boolean(errors.payment_date)}
            helperText={errors.payment_date}
            slotProps={{ inputLabel: { shrink: true } }}
          />
          <TextField
            select
            label="Método"
            value={values.method}
            onChange={(e) => update('method', e.target.value as PaymentMethod)}
            slotProps={NATIVE_SELECT}
          >
            {PAYMENT_METHODS.map((m) => (
              <option key={m} value={m}>
                {METHOD_LABELS[m]}
              </option>
            ))}
          </TextField>
          <TextField
            select
            label="Estatus"
            value={values.status}
            onChange={(e) => update('status', e.target.value as PaymentStatus)}
            slotProps={NATIVE_SELECT}
          >
            {PAYMENT_STATUSES.map((s) => (
              <option key={s} value={s}>
                {PAYMENT_STATUS_LABELS[s]}
              </option>
            ))}
          </TextField>
        </Stack>
        {saveError && (
          <Alert role="alert" severity="error" sx={{ mt: 2 }}>
            {saveError}
          </Alert>
        )}
      </DialogContent>
      <DialogActions>
        <Button onClick={onClose} disabled={saving}>
          Cancelar
        </Button>
        <Button variant="contained" onClick={() => void handleSave()} disabled={saving}>
          Guardar
        </Button>
      </DialogActions>
    </Dialog>
  )
}
```

  if (error) throw new Error(error.message)

export async function fetchOutstandingPayments(): Promise<PaymentRow[]> {
  const { data, error } = await supabase
    .from('payments')
    .select(PAYMENT_COLUMNS)
    .in('status', ['pendiente', 'parcial'])
    .order('payment_date', { ascending: true })
  if (error) throw new Error(error.message)
  return ((data as PaymentRow[] | null) ?? []).map(normalizeRow)

// Con adeudo follows the open rows, not the view: the two reads are not atomic
export function buildDebtGroups(
  players: PlayerRow[],
  statuses: PaymentStatusRow[],
  outstanding: PaymentRow[],
): DebtGroups {
  const stateByPlayer = new Map(statuses.map((s) => [s.player_id, s.payment_state]))
  const openByPlayer = new Map<string, PaymentRow[]>()
  for (const payment of outstanding) {
    const list = openByPlayer.get(payment.player_id)
    if (list) list.push(payment)
    else openByPlayer.set(payment.player_id, [payment])
  }
  const groups: DebtGroups = { con_adeudo: [], sin_pagos: [], al_corriente: [] }
  for (const player of players) {
    if (player.status !== 'activo') continue
    const open = openByPlayer.get(player.id)
    if (open) groups.con_adeudo.push({ player, payments: open })

    else groups.al_corriente.push(player)
  }

}

import { useEffect, useState } from 'react'
import type { ReactNode } from 'react'
import { Link as RouterLink } from 'react-router-dom'

function GroupSection({ state, count, children }: { state: PaymentState; count: number; children: ReactNode }) {
  const headingId = `group-${state}`
  return (
    <Box component="section" aria-labelledby={headingId} sx={{ mt: 3 }}>
      <Typography id={headingId} variant="h6" component="h2">
        {`${PAYMENT_STATE_LABELS[state]} (${count})`}
      </Typography>
      {count === 0 ? (
        <Typography color="text.secondary" sx={{ mt: 1 }}>
          Nadie en este grupo.
        </Typography>
      ) : (
        <List disablePadding>{children}</List>
      )}
    </Box>
  )
}

function PlayerLink({ player, children }: { player: PlayerRow; children?: ReactNode }) {
  return (
    <ListItemButton component={RouterLink} to={`/jugadores/${player.id}`} divider sx={{ display: 'block' }}>
      <ListItemText primary={player.full_name} secondary={playerCategoryText(player)} />
      {children}
    </ListItemButton>
  )
}

export function DebtorsPage() {
  const [groups, setGroups] = useState<DebtGroups | null>(null)
  const [loadError, setLoadError] = useState(false)
  const [reloadKey, setReloadKey] = useState(0)

  useEffect(() => {
    let active = true
    void Promise.all([fetchPlayers(), fetchPaymentStatuses(), fetchOutstandingPayments()])
      .then(([players, statuses, outstanding]) => {
        if (!active) return
        setLoadError(false)
        setGroups(buildDebtGroups(players, statuses, outstanding))
      })
      .catch(() => {
        if (active) setLoadError(true)
      })
    return () => {
      active = false
    }
  }, [reloadKey])

  function handleRetry() {
    setLoadError(false)
    setGroups(null)
    setReloadKey((k) => k + 1)
  }

  const total = groups ? groups.con_adeudo.length + groups.sin_pagos.length + groups.al_corriente.length : 0

  return (
    <Box sx={{ maxWidth: 720, mx: 'auto', mt: 4, px: 2 }}>
      <Typography variant="h4" component="h1">
        Quién debe
      </Typography>
      {loadError ? (
        <LoadError onRetry={handleRetry} />
      ) : groups === null ? (
        <Typography sx={{ mt: 2 }}>Cargando…</Typography>
      ) : total === 0 ? (
        <Typography color="text.secondary" sx={{ mt: 2 }}>
          No hay jugadores activos.
        </Typography>
      ) : (
        <>
          <GroupSection state="con_adeudo" count={groups.con_adeudo.length}>
            {groups.con_adeudo.map(({ player, payments }) => (
              <PlayerLink key={player.id} player={player}>
                <Stack spacing={0.5} sx={{ mb: 1 }}>
                  {payments.map((p) => (
                    <Stack key={p.id} direction="row" spacing={1} sx={{ alignItems: 'center', flexWrap: 'wrap', rowGap: 0.5 }}>
                      <Typography variant="body2">{`${paymentText(p)} · ${formatMoney(p.amount)}`}</Typography>
                      <Chip size="small" label={PAYMENT_STATUS_LABELS[p.status]} color={PAYMENT_STATUS_COLOR[p.status]} />
                    </Stack>
                  ))}
                </Stack>
              </PlayerLink>
            ))}
          </GroupSection>
          <GroupSection state="sin_pagos" count={groups.sin_pagos.length}>
            {groups.sin_pagos.map((player) => (
              <PlayerLink key={player.id} player={player} />
            ))}
          </GroupSection>
          <GroupSection state="al_corriente" count={groups.al_corriente.length}>
            {groups.al_corriente.map((player) => (
              <PlayerLink key={player.id} player={player} />
            ))}
          </GroupSection>
        </>
      )}
    </Box>
  )
}
